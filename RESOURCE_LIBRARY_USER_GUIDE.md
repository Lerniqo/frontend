# Resource Library - Quick Start Guide

## How to Use

### 1. Access the Resource Library

Navigate to the Learning Resources page in your application.

### 2. Choose Your View Mode

**By Matter** - Organize by subject areas (Algebra, Geometry, etc.)

- Best for topic-focused learning
- Hierarchical structure: Matter → Molecule → Atom → Particle

**By Grade** - Organize by grade levels (Grade 6-11)

- Best for curriculum-based learning
- Simple structure: Grade → Topics

### 3. Navigation Flow

#### By Matter Mode:

```
1. Select a Matter (e.g., "Algebra") from the left sidebar
2. Browse Molecules (e.g., "Linear Equations")
3. Click to expand and see Atoms (e.g., "Solving Equations")
4. Click an Atom to view its Particles
5. Click a Particle to learn more (opens concept-view)
```

#### By Grade Mode:

```
1. Select a Grade (e.g., "Grade10") from the left sidebar
2. Browse Topics displayed in a grid
3. Click any Topic to learn more (opens concept-view)
```

### 4. Using Search

1. Type any concept name in the search bar
2. View matching results with their full path
3. Click a result to:
   - Navigate directly to that concept (Particles/Topics)
   - Or jump to that section in the hierarchy (Matters/Molecules/Atoms)

### 5. Understanding the Interface

#### Left Sidebar (Sections)

- **Active Section**: Purple gradient background, white text
- **Inactive Section**: Gray background, dark text
- Click to switch between sections

#### Main Content Area

- **Expandable Items**: Have arrow icons (▶ or ▼)
- **Clickable Items**: Change color on hover
- **Back Button**: Appears when viewing Atom details

#### Visual Indicators

- 🟣 **Purple dot**: Section/category label
- **Gradient backgrounds**: Interactive elements
- **Border highlights**: Active/selected items

## Color Guide

| Color           | Usage                                  |
| --------------- | -------------------------------------- |
| Purple gradient | Active selections, primary actions     |
| Blue gradient   | Molecules (expandable items)           |
| Light purple    | Particles and clickable items          |
| Gray            | Inactive sections, neutral backgrounds |
| White           | Main content area                      |

## Keyboard Navigation

- **Tab**: Navigate through interactive elements
- **Enter**: Activate selected button/link
- **Escape**: Close search results (when implemented)

## Tips

1. **Quick Access**: Use the search bar to find specific concepts quickly
2. **Exploration**: Use By Matter to understand relationships between concepts
3. **Learning Path**: Use By Grade to follow curriculum order
4. **Back Navigation**: Use browser back button or the "Back" button in the interface

## Troubleshooting

### Search Not Working

- Make sure you've typed at least one character
- Search is case-insensitive - try different spellings
- Check if you're in the right view mode

### Page Not Loading

- Check your internet connection
- Refresh the page
- Clear browser cache if issues persist

### Navigation Issues

- Use the "Back" button in the interface
- Refresh page to reset state
- Try switching view modes

## Technical Notes

- All concept IDs are preserved in URLs for bookmarking
- State resets when switching between view modes
- Search results show the full path to help identify concepts
